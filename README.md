# 💻 Projeto Web - Plataforma Fitness

## 📌 Sobre o Projeto

Este projeto foi desenvolvido com o objetivo de praticar conceitos fundamentais de desenvolvimento web utilizando:

- HTML
- CSS
- JavaScript

A aplicação simula uma plataforma fitness contendo:

- Página inicial
- Área sobre a empresa
- Planos
- Login
- Cadastro
- Área do usuário
- Trabalhe Conosco
- Recursos de acessibilidade

---

# 🎯 Objetivos do Projeto

O projeto foi desenvolvido para praticar:

- Estruturação de páginas com HTML
- Estilização com CSS
- Manipulação de elementos com JavaScript
- Eventos com `addEventListener`
- Validação de formulários
- Responsividade
- Acessibilidade

---

# 🛠 Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript

# 🎨 Funcionalidades

## ✅ Home

Página principal contendo:

- Apresentação da plataforma
- Navegação entre telas
- Botões de acesso

---

## ✅ Sobre

Área com informações sobre a empresa e seus objetivos.

---

## ✅ Planos

Sessão contendo:

- Cards de planos
- Benefícios
- Valores
- Botões de contratação

---

## ✅ Login

Formulário de login estilizado com:

- Campos personalizados
- Botão responsivo
- Validação básica

---

## ✅ Cadastro

Formulário contendo:

- Nome
- CPF
- E-mail
- Senha
- Informações do usuário

---

## ✅ Trabalhe Conosco

Formulário para envio de currículo contendo:

- Nome completo
- E-mail
- Telefone
- Área de interesse
- Mensagem
- Upload de currículo

### Validações adicionadas:

- Campos obrigatórios
- Validação de e-mail
- Validação de telefone
- Limite de caracteres
- Restrição de arquivos

---

# ⚙️ JavaScript

O JavaScript foi utilizado para:

- Troca de telas
- Eventos de clique
- Controle da acessibilidade
- Envio do formulário
- Exibição de mensagens

### Exemplo:

```javascript
event.preventDefault();
alert("Currículo enviado com sucesso!");
```

# ♿ Acessibilidade

O sistema possui:

- Aumento de fonte
- Alto contraste
- Modo daltonismo

Tudo controlado por JavaScript através da adição de classes no `body`.
